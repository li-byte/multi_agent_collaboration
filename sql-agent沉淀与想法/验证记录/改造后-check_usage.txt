用量解析（token 从哪儿读）：

  ✓ OpenAI 风格 usage_metadata（langchain-openai 的标准位置）  → 1280 token
  ✓ 只有原始 response_metadata.token_usage（部分 provider 只给这个）  → 15 token
  ✓ prompt_tokens_details.cached_tokens（OpenAI 的另一种写法）  → 120 token
  ✓ 推理模型的思考 token 要单独记  → 230 token
  ✓ **没有任何用量字段** → 全记 0，绝不按字符数估算  → 0 token
  ✓ 根本没拿到原始响应（provider 不支持 include_raw）→ 也记 0  → 0 token

include_raw 的两种形状：

  ✓ 带 include_raw：拆出原始响应与解析结果
  ✓ 不带 include_raw：只有解析结果，原始响应是 None
  ✓ 解析失败：parsed 是 None，原始响应还在（照样能记用量）

时间字段（`_iso` 要幂等）：

  ✓ None → None
  ✓ 字符串 → 原样（不能再去调 .isoformat()）
  ✓ datetime → isoformat 字符串
  ✓ 没有 isoformat 的对象 → 原样返回，不炸

  ✓ 消耗明细 · 时间已是字符串（list_llm_calls 会先转好）  → created_at='2026-09-16T09:40:29+00:00'
